# simple-yoyaku-kanri

## ヘルスチェック

バックエンドサーバーの稼働状態とデータベース接続を確認：

```bash
# ヘルスチェックエンドポイント
curl http://localhost:4000/health

# 正常時のレスポンス
{
  "status": "ok",
  "db": true    # データベース接続成功
}

# DB接続失敗時のレスポンス
{
  "status": "ok",
  "db": false   # データベース接続失敗
}
```

## **⚠️ データベースリセットコマンド - 危険 ⚠️**

**本番環境や共有データベースでは絶対に実行しないでください。これらのコマンドはすべてのデータを完全に削除します。**

### 手動データベースハードリセット（開発環境専用）
```bash
cd backend

# ステップ1: ハードリセット（すべてのデータを破棄）
npm run db:reset:hard

# ステップ2: マイグレーションとシードの実行
npm run db:migrate:fresh
```

**これらのスクリプトは意図的に手動実行専用としており、他のスクリプトから自動実行されません。**

**実行前の確認事項:**
- `.env`の`DATABASE_URL`がローカル開発データベースを指していることを確認
- 本番/ステージング環境のデータベースに接続していないことを確認
- 必要に応じて重要なデータをバックアップ
